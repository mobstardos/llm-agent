# onec_designer_tools — MCP-сервер «Инструменты для разработки 1С»

Интеграция репозитория [comol/mcp_designer_tools](https://github.com/comol/mcp_designer_tools)
в llm-agent: 4 инструмента для [Конструктора MCP серверов для 1С](https://vibecoding1c.ru/#designer),
дающих ИИ-агенту выполнение кода, запросов и диагностику непосредственно в базе 1С.

## Что это и откуда

`ИнструментыДляРазработки.xml` — выгрузка справочника `APA_Инструменты`
Конструктора MCP: 4 инструмента, которые становятся доступны ИИ через протокол MCP.

| Инструмент | Параметры | Описание |
|---|---|---|
| **vcexecutecode** | `bslcode` — код на 1С | Выполняет произвольный код 1С в базе. Возвращает результат или описание ошибки. |
| **vcexecutequery** | `querytext` — текст запроса | Выполняет запрос, возвращает результат текстовой таблицей (заголовки + строки через «\|»). Пустой результат — заголовки и `(0 строк)`. |
| **vcvalidatequery** | `querytext` — текст запроса | Проверяет синтаксис запроса **без выполнения** (для валидации сгенерированных ИИ запросов). |
| **vcloggetlasterror** | — | Последняя ошибка Журнала регистрации за 24 часа (дата, событие, метаданные, описание). |

MCP-сервер llm-agent (`src/mcp_servers/onec_designer_tools/server.py`) — прокси:
он не говорит с 1С напрямую, а шлёт JSON-RPC 2.0 (`tools/call`) на HTTP-эндпоинт
Конструктора. Пятый инструмент `vc_tools_list` возвращает это описание для
обнаружения возможностей.

## Установка (настраиваемая часть — в 1С)

1. Установите **Конструктор MCP серверов** в вашу базу 1С
   (https://vibecoding1c.ru/#designer).
2. Загрузите `tools/ИнструментыДляРазработки.xml` стандартным механизмом
   загрузки данных Конструктора.
3. Опубликуйте HTTP-сервис базы через Apache:
   - `config/httpd.conf` — пример публикации (`/mcptest` → каталог публикации);
   - `config/default.vrd` — дескриптор публикации 1С;
   - `config/mcpconfig.json` — пример адреса (`http://localhost/mcptest/hs/mcp`).
4. Пропишите окружение для llm-agent:
   - `ONEC_MCP_URL` — адрес эндпоинта (по умолчанию `http://127.0.0.1:8795/mcp`);
   - `ONEC_MCP_TOKEN` — необязательный Bearer-токен.
   Значения можно задать в `config/settings.yaml` (секция
   `mcp_servers.onec_designer_tools.env`) или в `.env`.

Проверка: агент `onec_designer_tools` → инструмент `vc_tools_list` (работает
всегда), затем `vcvalidatequery` с заведомо корректным запросом.

## Безопасность

> **Внимание:** `vcexecutecode` и `vcexecutequery` выполняют произвольный код и
> запросы в базе данных. Используйте только в доверенном окружении.

В llm-agent оба помечены `danger: external` → проходят через approval gate
(модальное окно подтверждения), `vcvalidatequery`, `vcloggetlasterror`,
`vc_tools_list` — `danger: read`.
