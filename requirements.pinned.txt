# Что изменилось vs оригинального requirements.txt:
#
#  1. Критичные пакеты переключены с >= на ~= (compatible release).
#     ~=X.Y.Z разрешает патч-апдейты (Z), но не минорные (Y) — это
#     баланс между фиксами безопасности и защитой от сюрпризов.
#
#  2. Закреплены версии 7 пакетов, обновление которых рискует сломать
#     сборку (список с обоснованиями ниже):
#       - mcp              (mcp 2.x удалил @app.list_tools() — критично)
#       - fastapi          (Breaking changes в lifespan/Pydantic v2)
#       - pydantic         (API стабилен, но v2 → v3 будет болезненно)
#       - psycopg          (async API стабилен с 3.2, но есть нюансы)
#       - openai           (API Python SDK менялся несовместимо в 1.x)
#       - uvicorn          (websockets & lifespan настройки)
#       - httpx            (http2 — нестабилен на Windows)
#
#  3. Некритичные пакеты (tree-sitter-грамматики, whisper, pandas, ...)
#     оставлены с >= — их обновления редко ломают.
#
# Применение:
#   cp requirements.txt requirements.txt.bak   # бэкап оригинала
#   cp /path/to/patch/requirements.pinned.txt requirements.txt
#   pip install -r requirements.txt            # проверить сходимость
#   git diff requirements.txt                  # показать изменения
# ═══════════════════════════════════════════════════════════════════════
