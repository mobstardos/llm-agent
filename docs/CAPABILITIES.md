# ✨ Полное описание возможностей LLM Agent

> Что умеет система, из чего состоит и где это включается. Установка и запуск —
> [GETTING_STARTED.md](GETTING_STARTED.md), ответы на проблемы — [FAQ.md](FAQ.md),
> архитектура — [ARCHITECTURE-V2.md](ARCHITECTURE-V2.md).

LLM Agent — **мультиагентная система правки файлов и баз данных** поверх
LLM-провайдеров. Вы формулируете задачу в чате; супервизор строит план,
оркестратор раздаёт подзадачи профильным агентам, агенты действуют через
MCP-инструменты, каждая операция записывается в журнал и может быть откатена.

---

## 1. Чат и ядро выполнения

- **Веб-чат** (`/`) — стриминговые ответы (токены появляются по мере генерации),
  история чатов с переключением («Последние чаты» в шапке), заголовки чатов
  генерируются локальной моделью.
- **Супервизор** разбивает сложную задачу на план (DAG-шаги), показывает шаги
  в чате; планы переживают рестарт (`src/supervisor/`).
- **Оркестратор** выбирает агента на каждый шаг; параллельные подзадачи.
- **Рассуждения (reasoning)** — модели, отдающие reasoning-контент, показывают
  его отдельными «дорожками» шагов (авто-сворачивание при первом токене ответа).
- **Подтверждения (approval)** — опасные операции (запись файла, shell, SQL)
  показывают модальное окно с аргументами; можно разрешить «всегда для
  инструмента/файла/папки».
- **Политики безопасности** (`src/policies.py`) — TTL, лимиты, история
  удалений, экспорт/импорт JSON, бэкапы политик.
- **Кэш ответов LLM** (`data/cache.sqlite`) — повторные одинаковые запросы
  дешевле; метрики hit/miss видны в шапке и настройках.
- **Бюджеты петли** — `LOOP_MAX_ITERATIONS/TOKENS/DURATION`, софт/хард-лимиты,
  kill-лимит — агент не уйдёт в бесконечный цикл.
- **Фолбэки моделей** — если endpoint не отвечает, запрос уходит по цепочке
  (`LLM_FALLBACKS` → `models.yaml`); в чате появляется бейдж «♻️ переключился
  на …». Стрим, уже отдавший токены, и переполнение контекста не фолбэкаются.

## 2. Выбор модели (13 провайдеров)

Кнопка модели в шапке — комбо-бокс с поиском, группы провайдеров, бейджи
«💻 локальная», «без tools», причина недоступности («нет ключа DEEPSEEK_API_KEY»):

| Провайдер | Тип | Примечание |
|---|---|---|
| qwenproxy | браузерный (Node-прокси к веб-чату Qwen) | работает из РФ, без ключа API |
| DeepSeek | API / браузерный (куки) | работает из РФ |
| Ollama | локальный | без интернета, помечен 💻 |
| LM Studio | локальный | OpenAI-совместимый локальный сервер |
| OpenAI | API | из РФ даёт 403 region — честно предупреждаем |
| OpenRouter, SiliconFlow | агрегаторы | есть free-модели |
| VseGPT, ProxyAPI | агрегаторы РФ | OpenAI-совместимые |
| Anthropic, Gemini, Groq, Mistral | API | ключи соответствующих сервисов |

- Формат ID: `provider/model` (например `deepseek/deepseek-chat`); короткие
  имена тоже работают.
- Выбор сохраняется в `config/runtime.yaml` и переживает перезагрузку.
- **Локальные микрозадачи** (файл `src/background/micro_tasks.py`) крутятся на
  маленькой Ollama-модели (2 ГБ VRAM): заголовки чатов и планов, теги
  сообщений, дайджест журнала — ноль затрат облака; при активном локальном
  чате воркер встаёт на паузу (свопов VRAM нет).

## 3. Агенты (37)

Каждый агент — папка в `agents/` (промпт + user-инструкция + yaml-манифест)
и свой MCP-сервер с инструментами. Управление: ⚙️ → «Агенты» (включение,
параметры, проверка).

| Категория | Агенты |
|---|---|
| Разработка | `file`, `code_analysis`, `git`, `github`, `frontend`, `debug`, `testing`, `lsp`, `cicd`, `build`, `environment`, `network` |
| Данные и БД | `postgres`, `mysql`, `db_extended`, `data`, `storage` |
| 1С | `onec`, `onec_query`, `onec_dcs`, `onec_forms`, `onec_metadata`, `onec_designer`, `onec_tests` |
| Документы и медиа | `document`, `image`, `media` |
| Веб | `browser`, `http` |
| Прочее | `shell`, `deepseek`, `documentation`, `journal`, `monitoring`, `kubernetes`, `security`, `migration` |

## 4. MCP-инструменты (39 серверов)

MCP-серверы (`src/mcp_servers/*`) дают агентам безопасные инструменты:
файловая система (чтение/запись/патчи), shell (с подтверждением), SQL к
PostgreSQL/MySQL, HTTP-клиент, браузер (Playwright: открытие страниц,
скриншоты, клики), LSP (диагностика кода), grep-поиск по коду, разбор
графов кода (tree-sitter), документы (PDF/DOCX/XLSX), OCR (tesseract),
vision-описание картинок, транскрипция аудио (faster-whisper), 1С: запросы,
ДСК, формы, метаданные, конфигуратор (логи, дифф), тесты (Vanessa/YAxUnit),
журнал, память, мониторинг и др. Реестр и состояние — ⚙️ → «MCP» и
«Capabilities» (`capabilities/*.yaml` описывают, что доступно).

## 5. Память

(`src/memory/`, `docs/DATABASE.md`)

- **Эпизодическая** — события диалогов; **семантическая** — факты и знания
  (векторный поиск); **процедурная** — успешные приёмы; **рабочая** — текущий
  контекст; **граф знаний** — сущности и связи, парсеры кода Python/TS/JS.
- Хранилища: SQLite + **LanceDB** локально; при наличии PostgreSQL —
  pgvector-вариант, двойная запись (`DUAL_WRITE_ENABLED`), миграции
  (`/api/db/migrate-vectors`, `/api/db/migrate-memory`).
- **Эмбеддеры**: `hash` (мгновенный, без сети) или `bge-m3`
  (`AGENT_MEMORY_EMBEDDER=auto` скачает модель, если получится).
- **AGE-граф** (Apache AGE в PostgreSQL): статистика, Cypher-запросы из UI
  (⚙️ → AGE), «кто использует этот файл», синхронизация графа.

## 6. Журнал действий (Journal)

(`docs/JOURNAL.md`, `src/journal/`)

- Каждое действие агента — запись в журнал (SQLite, зеркало в PostgreSQL).
- **Откат (rollback)** — файловые операции и записи БД разворачиваются
  (⚙️ → Rollback, `/api/registry/rollback/...`).
- **Реплей** — повторное выполнение последовательности действий.
- **Ретенция** — автоочистка старых записей (`PG_RETENTION_DAYS` и политики).
- **Дайджест** — локальная модель раз в цикл пишет сводку по журналу
  (⚙️ → «Дайджест журнала», `/api/digest/latest`).
- Свой MCP-сервер и CLI (`python -m src.journal.cli`).

## 7. Расширение браузера (Bridge, v1.2.0)

(`README.md` → «Bridge», `features/bridge/`)

- Chromium + Firefox (отдельные манифесты).
- **🔑 Куки веб-чатов**: кнопки DeepSeek/Qwen в попапе открывают страницу
  логина, после авторизации куки сами прилетают в систему
  (`/api/bridge/cookies`), можно просмотреть/удалить.
- **Alt+Shift+B** — разбудить агента на текущей странице (панель, фокус,
  подхваченное выделение).
- **Суммаризация страницы** из контекстного меню — полный текст уходит агенту.
- Индикация подключения, счётчики событий.

## 8. Веб-интерфейс

- **Чат**: стриминг, шаги плана, reasoning, подтверждения, бейджи локальной
  модели и фолбэков, последние чаты, выбор модели, кнопка проекта 📁.
- **⚙️ Настройки** — 14 вкладок: Система (здоровье, кэш, обогащение, дайджест),
  Агенты, MCP, Capabilities, Политики (экспорт/импорт/бэкап), Бэкапы
  (создать/восстановить/скачать), Синонимы поиска, AGE (Cypher), CDC,
  История (диффы реестра), Профили (сохранить/применить/импорт/экспорт),
  Аудит, Rollback, Диагностика (snapshot + промпт оркестратора).
- **📊 Аналитика** (`/analytics`): сводка, по дням/часам, агентам, темам,
  инструментам, файлам, обогащению; материализованные представления в PG.
- **🎓 Интерактивный курс** (`/guide`): пошаговый онбординг с живыми
  проверками API, квизами и прогрессом.
- REST API: ~90 эндпоинтов (см. `src/main.py`), WebSocket `/ws` — события чата.

## 9. Данные и инфраструктура

- **PostgreSQL**: автодетект со словарём дефолтных паролей (24-b), роль
  `llmagent`, идемпотентная схема (`db/init.sql`, `journal.sql`, `ops.sql`,
  `analytics.sql`, `age_schema.sql`), репликатор с backoff (60с → 300с),
  пул соединений, работающий на любом event loop (Windows Proactor —
  через selector-мост), честные сообщения об недоступности без спама.
- **CDC** (`src/cdc/`): notify-воркер + Kafka-публикация изменений
  (`KAFKA_ENABLED`).
- **Бэкапы**: авто по расписанию + ручные, ротация `BACKUP_KEEP_LAST`,
  восстановление из UI.
- **Кластер** (`src/cluster/`): несколько инстансов через Redis-шину
  (heartbeat, WS-мост).
- **Телеметрия петель** (`data/loop_telemetry.sqlite`) и `/metrics`.

## 10. Безопасность

(`docs/SECURITY.md`)

- Подтверждения опасных действий (approval-modal) с запоминанием уровня.
- Политики инструментов с TTL и лимитами; история удалений; экспорт/импорт.
- Аудит всех административных действий (⚙️ → Аудит).
- Секреты не пишутся в логи (DSN маскируется: `dsn_view`), куки хранятся
  локально в `.env`/реестре веб-куки без значений в API-ответах.
- Rollback любых файловых изменений агентов.

## 11. Тестирование и качество

- **Harness** (`harness/`): сценарии YAML, моки LLM, хаос-инженерия
  (таймауты), песочница, отчёты, baseline — `docs/STRUCTURE.md`.
- **Стенд-скрипты** (`scripts/test_*.py`): мост (78 проверок), PG-автодетект
  (51), модели/микрозадачи (56), провайдеры (42), история (51), journal (42),
  db_pg (61), ops_pg (99), pg_windows_compat (70), стадии 1–5 и др.
- pytest-набор в `tests/` + харнесс (`harness/tests`).
- `scripts/test_onboarding.py` — целостность онбординга: bat-файлы, точки
  входа, документация, интерактивный курс.
